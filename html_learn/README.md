# 岁时记 · 传统黄历

一个纯前端（HTML + CSS + JS）的传统古风黄历网页，双击 `index.html` 即可打开，无需联网也能使用。

## 功能

- **农历查询**：输入日期（1900-01-31 ~ 2100-12-31），显示农历日期、年干支、日干支、生肖、时辰、距今
- **二十四节气**：显示所选日期所处节气与下一节气倒计时，点击查看节气详情
- **养生之道**：随所选节气给出顺应天时的养生建议，点击进入卷轴详情——宜/忌一览 + 「起居 / 饮食 / 运动 / 情志」四个标签页交互切换，附《黄帝内经》四时养生要旨
- **节日与倒计时**：显示最近节日及天数（春节、中秋等农历节日 + 元旦、国庆等公历节日 + 母亲节、父亲节等浮动节日），当日节日以印章标签列出，均可点击查看详情
- **月历**：可打开月历弹窗，选择日期直接查询；支持给日期「落印」标记（可附备注，存于本机 localStorage），节日日与节气日各有小圆点提示
- **重要日期**：主页「重要日期」卡列出全部印记——七天之内的以小字直接显示倒计时，其余（远期与已过）默认收起，按下「其余印记」按钮展开；点击整卡进入「印记簿」，点任意一条即刻跳转该日黄历
- **名号（用户）系统**：首次进入必须取名号（仅用户名、不可重复），之后自动登录；每位用户的选择（查询日期、星期格式、背景画）与印记、操作事件（落印/除印/择日/查询/换画等）各自独立记录，换名号即换各自界面，再打开网页也不是新界面
- **水墨背景**：6 幅程序绘制的 SVG 水墨画（远山叠翠、寒梅映月、竹影清风、孤舟蓑笠、山间飞瀑、荷塘清趣），按「隔日」自动轮换，点击右上角朱红印章可手动换画

## 文件结构

- `index.html` — 页面结构
- `style.css` — 古风样式（宣纸、朱砂、卷轴弹窗）
- `script.js` — 全部逻辑：
  - 农历换算（1900-2100 数据表）、农历↔公历互转
  - 节气计算（寿星公式）、节日数据库、日干支
  - 水墨画生成、月历与印记、弹窗交互
